# 📦 Módulo 1: Sintaxe, Lógica e Otimização

Bem-vindo ao primeiro módulo da Fase 1. O objetivo deste módulo foi estabelecer a sintaxe base da linguagem C e entender como o compilador traduz instruções diretas para o processador, com forte ênfase em controle de fluxo, escopo de variáveis e manipulação de memória bit a bit.

## 📋 Resumo de Tópicos Estudados

Abaixo está o checklist de conceitos validados neste módulo. 
👉 **[Clique aqui para ler minhas anotações detalhadas e explicações teóricas de cada tópico](./Topicos/README.md)** *(Neste link você também encontra os links de códigos dos exercícios práticos de fixação).*

- [x] **Tópico 1:** Tipos Primitivos, Modificadores de limite e Casting.
- [x] **Tópico 2:** Operadores Lógicos e Otimização Extrema com Bitwise (`<<`, `>>`, `&`, `|`, `^`).
- [x] **Tópico 3:** Controle de Fluxo (*Jump tables* com `switch`) e Loops (`for`, `while`, `do-while`).
- [x] **Tópico 4:** Criação de Funções, Isolamento na *Stack* e Escopo Global vs Local.

# Fase 1: Arquitetura de Memória e Estruturas Fundamentais

**Foco da Fase:** Sair do zero ao domínio completo de como a linguagem C gerencia a memória RAM de forma isolada, compreendendo os limites de hardware, alocação estática e otimização de processamento.

Nesta fase, a linguagem C é utilizada como uma ferramenta de compreensão de base, operando estritamente via terminal (CLI) para construir uma fundação sólida em algoritmos antes da introdução de bibliotecas gráficas.
